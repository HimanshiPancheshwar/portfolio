## 🎨 Features & Design Highlights

- **Aesthetic Design**: Glassmorphic dark theme (with light theme switcher), vibrant neon emerald & cyan glowing accents, and clean modern typography (`Plus Jakarta Sans` & `JetBrains Mono`).
- **Interactive Project Filtering**: Instant filtering across **Power BI & BI**, **Python & Engineering**, and **Data Analytics**.
- **Architectural Modals**: Detailed popups highlighting Star Schema data modeling, semi-additive measures (`LASTNONBLANK`), Python regex skill extraction, and financial EDA.
- **Micro-Animations**: Animated live status badge, smooth scroll progress indicator, stat counter animations, and card hover effects.
- **GitHub Pages Ready**: Zero build steps or heavy node modules needed—pure Vanilla HTML5, CSS3, and JavaScript that works immediately upon deployment.
- **Fully Responsive**: Optimized for all devices from smartphones to desktop displays.

## 💻 Local Preview

You can view the portfolio locally using any browser:

### Option 1: Direct File Open
Double-click `index.html` or open it with your browser:
```powershell
Start-Process "index.html"
```

### Option 2: Local Python Server (Recommended)
Run Python's built-in HTTP server:
```powershell
python -m http.server 3000
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.

## 🚀 How to Deploy to GitHub Pages

The repository has already been initialized and linked to `https://github.com/HimanshiPancheshwar/portfolio.git`.

### Step 1: Commit Your Files
```powershell
git add .
git commit -m "feat: initial release of modern data analyst web portfolio"
```

### Step 2: Push to GitHub
```powershell
git branch -M main
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. Go to your repository on GitHub: [https://github.com/HimanshiPancheshwar/portfolio](https://github.com/HimanshiPancheshwar/portfolio)
2. Click **Settings** (top navigation tab)
3. On the left sidebar, click **Pages**
4. Under **Build and deployment** > **Branch**:
   - Select Branch: `main`
   - Select Folder: `/ (root)`
5. Click **Save**

Within 1–2 minutes, your website will be live at:
**`https://himanshipancheshwar.github.io/portfolio/`**
