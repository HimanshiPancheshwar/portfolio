DAX Data Model & Advanced Analytics

Architecture Highlights:

This project models enterprise-level retail and sales operations by combining transaction data (Internet Sales) with inventory snapshots (Product Inventory) and rich dimension hierarchies.

  • Star Schema Design: Centralized fact tables connected via 1-to-many relationships to Customer, Product, Sales Territory, Date, and Temperature dimensions.
  • Filter Context Transition: Utilizing CALCULATE, REMOVEFILTERS, and boolean criteria to generate benchmark metrics regardless of slicer states.
  • Semi-Additive Calculations: Solving non-aggregatable inventory metrics over time with LASTNONBLANK and PARALLELPERIOD.
  • Custom Composite Keys: Dynamically linking regional temperature fluctuations to sales performance using composite relationship keys.

Job Intelligence Scraper & Matcher

Architecture Highlights:

A production-style Python application for automated job market intelligence extraction and candidate matching.

  • Dual API Ingestion: Ingests live job postings across SerpAPI Google Jobs and Exa API engines.
  • Data Normalization: Sanitizes messy JSON payloads into standardized internal relational formats.
  • Automated Skill Extraction: Parses raw descriptions to identify tech stacks (Python, PostgreSQL, AWS, Docker, Git).
  • PostgreSQL Atomicity: Transactional updates across companies, search history, and job listings with UNIQUE(job_url) deduplication.
  • Candidate Match Scoring: Computes algorithmic compatibility score: (matched_skills / required_skills) * 100.
